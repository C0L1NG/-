# OKX / Wise 风格页面改造

日期：2026-10-29。本轮修改正式 Web 共享组件，并同步静态展示版。

## 实际改动

- 老板 PC：将横向工作区导航改为桌面固定侧栏；首屏并列展示平台可用余额与资金待办；累计收益、GMV、代理佣金和人数作为次级指标；固定分润规则折叠展示。保留既有资金入口、团队、审计、日期和导出。
- 代理手机网页：移除重复的首页页签与单独身份条；改为昵称头像、深绿资产卡、浅绿提现主按钮、圆形快捷入口和连续活动列表。身份层级放到顶部，四 Tab 保留。
- 统一移动端深浅色表面、按钮、列表图标和选中导航；今日预计为负数时使用负向颜色。大金额采用 Geist 的 tabular 数字，订单/精确审计列继续使用等宽字体。
- Geist Sans / Mono 从现有 Next.js 分发中的字体复制到 public/fonts，本地加载并附官方 OFL 许可；展示同步覆盖字体、说明和许可，新增二进制字体及许可同步断言。

参考页面：[OKX](https://www.okx.com/)、[Wise 账户](https://wise.com/gb/account/)。本次为本平台的原创组件调整，不使用第三方商标或冒充官方产品。
